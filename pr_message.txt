### Why tools get placed in the Conflicts list (for reference):
When tools are flagged with conflicts, they are held back from merging for manual review. Common triggers include:
1. **Missing Critical Fields:** Entries lacking essential metadata such as repository URL, main programming language, or description.
2. **Language Mismatch:** Discrepancies between the primary language stated in the publication/metadata and the codebase detected on GitHub.
3. **Duplicate Entry:** The tool name already exists in the database with different metadata.
4. **Incorrect Repository Link:** Automated scraper links pointing to non-existent (404) repositories.
